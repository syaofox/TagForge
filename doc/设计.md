
# 项目需求：TagForge — LoRA 数据集图片打标工具

## 一、项目概述

开发一个名为 **TagForge** 的 Web 端图片打标工具，专门用于 LoRA 模型训练数据集的批量标注。技术核心为 **Python + NiceGUI**，采用 **纯异步并发** 调用大模型 API，**不依赖任何传统数据库**（PostgreSQL/MySQL），所有数据以文件系统 + JSON 方式存储。最终通过 **Docker Compose（最新版 V2，无需声明 version）** 一键部署，仅供单人局域网使用。

---

## 二、技术架构硬性要求（必须遵守）

1. **Web 框架**：仅使用 **NiceGUI (>=2.0.0)**，不拆分前后端。所有 UI 组件用 Python 编写。
2. **异步处理**：所有涉及大模型 API 调用的逻辑必须使用 `async/await`。使用 `asyncio.Semaphore` 控制并发数（默认 5）。UI 必须保持响应，严禁阻塞主线程。
3. **数据存储（零数据库）**：
   - 图片存放在 `datasets/{项目名}/images/`。
   - 标签存放在 `datasets/{项目名}/labels/` 下，与图片同名（扩展名 `.txt`）。
   - 短标签模式：txt 内存放逗号分隔的关键词（如 `1girl, blonde hair, smile`）。
   - 自然语言模式：txt 内存放完整描述句。
   - 项目列表和全局配置（API Key、Base URL、默认 Prompt）存放在 `config/settings.json`。
4. **图片状态判定**：程序启动时扫描 `datasets/` 目录下的子文件夹作为项目列表。若 `labels/` 下存在同名 `.txt` 且内容非空 => 状态为“已标注”；否则为“待标注”。
5. **容器化部署**：提供 `Dockerfile` 和 `docker-compose.yml`（**不包含 version 字段**，仅需一个服务容器，无需 Postgres/Redis 附加容器）。

## 四、UI 布局与界面示意（参照以下线框图实现）

### 1. 整体布局（三栏式）
- **顶栏**：左侧 Logo“⚒️ TagForge”，右侧放置「深色主题切换开关」和「帮助」按钮。
- **左侧面板（固定宽度 280px）**：放置模型配置、API Key、打标模式、系统提示词、导出按钮。
- **主区域**：上方是工具栏（显示当前项目名 + 上传按钮 + 批量标注按钮 + 进度条）。下方是图片网格（`ui.grid`）。
- **右侧详情面板**：点击图片后滑出（占屏幕 40% 宽度），带关闭按钮和上一张/下一张导航。

### 2. 图片卡片样式（重要细节）
每张卡片高度固定（约 220px），内容为：
```
┌─────────────┐
│ [缩略图 160px]│
│ girl_01.jpg  │
│ 🟢 已标注    │
└─────────────┘
```
- 缩略图居中裁剪（`cover` 模式）。
- 状态徽章使用不同颜色背景（绿色/黄色/蓝色/红色）。

### 3. 批量进度浮窗（Modal）
点击批量标注时，弹出一个非阻塞的模态框，内嵌 `ui.linear_progress` 和一个滚动日志区域（显示每张图的处理结果，如“girl_01.jpg ✅ 成功 (1.2s)”）。提供「后台运行」和「终止」按钮。

## 六、并发与防卡死策略（关键）

- 使用 `asyncio.Semaphore(5)` 限制最大并发数。
- 在批量处理的 `for` 循环中，每处理完一张图，必须执行以下操作刷新 UI：
  ```python
  progress.value = (idx + 1) / total
  await asyncio.sleep(0.01)  # 让出事件循环给 NiceGUI
  ```
- 所有异步任务启动前，必须检查当前项目是否为空。

## 七、Docker 部署文件要求（使用最新 Compose 规范，无版本号）

### Dockerfile
- 基于 `python:3.12-slim`
- 工作目录 `/app`
- 安装 `requirements.txt`（内容：`nicegui`、`openai`、`httpx`、`pillow`、`python-multipart`）
- 暴露端口 `8080`
- CMD 执行 `python main.py`

### docker-compose.yml（⚠️ 注意：无 version 字段）
```yaml
services:
  tagforge:
    build: .
    ports:
      - "8080:8080"
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - ./datasets:/app/datasets
      - ./config:/app/config
    restart: unless-stopped
```
*(注：启动时使用命令 `docker compose up -d`，而非旧版的 `docker-compose`)*
